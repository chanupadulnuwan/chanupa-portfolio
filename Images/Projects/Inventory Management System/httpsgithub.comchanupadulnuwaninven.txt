At the time, C# and OOP concepts were completely new to us, so even though this started as a “basic CRUD project,” it became one of the projects where we learned the real foundation of software development.
We built a desktop-based Inventory Management System using C# WinForms, .NET 8, and MySQL. Through this project, we explored concepts like object-oriented programming, database design, desktop application architecture, and how real business workflows can be automated through software.
Some of the features we implemented included:
• User authentication and role-based access
• Product and supplier management
• Stock tracking and sales processing
• Purchase order handling
• Reporting and analytics dashboards
• CRUD operations with parameterized SQL queries
• Real-time data presentation using DataGridView
We also structured the application using an MVC-inspired approach with separate Views, Models, and Controllers to keep the project organized and maintainable.
What makes this project special to me is not how advanced it was, but how much it taught us as beginners. It was one of the projects that helped me truly understand the basics of C#, OOP principles, and desktop application development.
Grateful for the experience and teamwork, and it’s interesting to look back now and see how much we’ve grown since then 🚀
